#Customer Segmentation Analysis

Project Overview

This project focuses on segmenting customers based on their demographics, purchasing behavior, and spending patterns.

The analysis was created using Microsoft Power BI to understand different customer groups and identify useful customer insights.

Objective

The main objectives of this project are:

- Segment customers based on their behavior and demographics.
- Analyze customer purchase patterns.
- Understand customer spending behavior.
- Compare different customer segments.
- Create visualizations to present key findings.

Tools Used

- Microsoft Power BI
- Microsoft Excel

Dataset

The dataset contains customer information such as:

- Customer ID
- Age
- Gender
- City
- Monthly Income
- Purchase Frequency
- Average Order Value
- Total Spend
- Website Visits
- Discount Usage
- Customer Segment

Customer Segments

Customers are divided into three segments:

- High Value – customers with higher spending and purchase frequency.
- Regular – customers with moderate spending and purchasing behavior.
- Low Value – customers with comparatively lower spending and purchase frequency.

Dashboard

The Power BI dashboard includes:

- Total Customers
- Total Spend
- Average Order Value
- Average Purchase Frequency
- Customers by Segment
- Spending by Segment
- Spending by City
- Purchase Frequency vs Total Spend
- Gender-based analysis

Key Insights

- Customers can be grouped into different segments based on their purchasing behavior.
- High-value customers contribute a larger amount of spending.
- Regular customers represent a significant portion of the customer base.
- Purchase frequency can be compared with total spending to understand customer behavior.
- Demographic information such as age, gender, and city can help understand customer preferences.

Conclusion

This project demonstrates how Power BI can be used for customer segmentation and analysis. The dashboard provides a simple visual understanding of customer behavior, spending patterns, and demographic characteristics.
